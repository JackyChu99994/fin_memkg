# 行情数据需求与验收范围

任务来源固定为 `scripts/realfin_contract.py` 中的提交和 SHA-256。官方 README 的统一日期说明与部分任务正文不一致；以固定版本的具体任务字段记录差异，不自动改写所有任务日期。

| 优先级/范围 | 输入 | 完成条件 | 本次实现或证据 |
|---|---|---|---|
| 必须：日线底座 | 已知股票、基准日、区间 | 本地读取、上市日期过滤、缓存范围明确 | `market_snapshot.py`；原子发布、限时补采、专项测试 |
| 必须：task_01 | 300 开头股票；2026-03-31；RSI14/MACD/MA/量能 | 300 秒内写结果、官方自动评分、独立复算 | `validate_task01.py`、`audit_stage3.py` |
| 必须：task_36 | 2024-08-22；最近五个交易日的 30 分钟价量及日收盘 | 探测目标历史覆盖；真实分钟或明确标注题目允许的替代；480 秒 | `probe_intraday.py`、`validate_task36.py` |
| 必须：细分行业 | 股票→统一分类层级→来源与观察时间 | 可统计覆盖与冲突；历史时点不足时明确拒绝或标记 | `market_sectors.py`，实际覆盖见验收摘要 |
| 必须：换手率 | 历史量与流通股本来源 | 明确百分比单位，统计异常，抽样核验 | `validate_fields.py` |
| 必须：流通市值口径 | 不复权价格＋带生效/可知日期的股本 | 只计算有证据的历史值；缺失不冒充精确值 | `market_fields.py` |
| 必须：缓存更新 | 旧分片、新起止日期、新股票池 | 补历史、更新日期、不混复权、不混股票池、失败保留旧快照 | `test_market_snapshot.py` |
| 必须：交接 | API 示例、来源、复现命令、限制 | 后续人员可以重复运行验收 | `STAGE3_HANDOFF.md` |

## 官方题目涉及的额外数据

以下是数据需求提示，不是已经完成的逐题求解或评测。

- task_02：399006 与上证指数；当前默认指数快照只有 399006。
- task_11、14、20、33：细分行业及部分指数/市值条件；当前行业归属不等于历史归属。
- task_16：估值；日线本身不能替代历史 PE。
- task_17：资金流；日线价量不是主力资金流的同义字段。
- task_18、19、28、31、32 等：长窗口或跨周期预热；2024-01 开始的数据可能不足，应先检查具体窗口。
- task_23、30、33、37：换手率、股本或市值；核对单位与历史可用性。
- task_34：ETF 成分；普通行业分类不能替代历史 ETF 成分。
- task_37：封单或尾盘分钟等字段；task_36 的日线替代规则不能未经核对直接推广。
- task_39、40：利率、商品等外部数据；当前股票日线缓存不覆盖这些来源。

全市场扩展和上述额外数据按后续评测需要添加。必须先写明支持的题目、字段和日期范围，才能判断单题是否能在 180–600 秒预算内完成；缓存未命中的全市场采集不能无条件承诺这个时限。
