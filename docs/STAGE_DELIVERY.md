## 剩余限制与后续工作

1. **历史分钟数据**：已验证的新浪/腾讯接口无法提供 task_36 所需的 2024-08-16 至 2024-08-22 数据。自动模式采用题目允许、明确标注的日线近似，不能证明真实分钟信号；仍需补充该历史区间的可靠来源。
2. **历史行业与市值**：当前行业映射完整，不等于历史时点分类完整；历史查询默认拒绝直接使用当前分类。准确的历史流通市值还需要不复权价格、生效日期和信息可知日期齐备的股本数据。
3. **时间偏差边界**：股票池来自当前存续名单，不补回已退市股票；前复权行情是采集时版本，未建立历史复权因子档案。基准日过滤不能消除这些偏差。
4. **评测范围**：两题仅完成官方自动检查，未运行 LLM judge，`overall_score` 为 null。通用 Agent 联调、KG 接入和完整 40 题评测仍待完成，不能据此宣称任意题目均已满足。
5. **市场与字段范围**：当前清单源支持创业板和深圳主板，沪市主板、科创板及其他题目涉及的指数、资金流、ETF、利率、商品等仍需按需扩展。
6. **复现依赖**：原始行情、运行缓存、虚拟环境和 `.env` 不随 Git 提交；新环境需按交接文档安装依赖并准备数据。行业字典解包依赖支持 RAR 的 `tar`，Windows 本机已验证。

完整接口、PowerShell 命令和网页使用方式见 [交接文档](STAGE3_HANDOFF.md)。本次提交包含源码、测试、依赖说明、文档和轻量验收证据。
